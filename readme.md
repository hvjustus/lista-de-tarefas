# Lista de Tarefas

Uma aplicação simples de lista de tarefas feita com HTML, CSS e JavaScript (ES Modules).

Permite adicionar tarefas com título e descrição, salvar no `localStorage` e renderizar automaticamente ao recarregar a página.

## Funcionalidades

- Adicionar tarefa  
- Persistência com `localStorage`  
- Renderização automática ao recarregar  
- Layout responsivo

## Estrutura

```
.
├── index.html
├── index.css
├── index.js
└── model/
    └── Task.js
```

## Como rodar

Como o projeto usa módulos ES6, é necessário rodar com um servidor local.

### VSCode
Use a extensão Live Server

ou

### Node
```bash
npx serve .
```

Depois abra no navegador.
